# Q1.List 5 common issues users face with USB keyboards or mice on laptops, and write one possible solution for each.
Ans.## 🖱️ Common USB Keyboard and Mouse Issues on Laptops

| No. | Common Issue | Possible Solution |
|---|---|---|
| 1 | Keyboard or mouse is not detected. | Unplug the USB device and reconnect it to another USB port. |
| 2 | Keyboard keys or mouse clicks are not responding. | Check the device connection and restart the laptop. |
| 3 | Mouse pointer moves erratically. | Clean the mouse sensor and use it on a suitable surface. |
| 4 | USB device connects and disconnects repeatedly. | Check the USB cable for damage and try another USB port. |
| 5 | Keyboard or mouse works slowly or freezes. | Update or reinstall the USB device drivers through Device Manager. |

### ✅ Conclusion
Regular maintenance, proper USB connections, and updated drivers can help prevent common keyboard and mouse problems on laptops.
# Q2.Simulate a troubleshooting flow: Your Bluetooth headphones are not connecting to your phone. Write the exact step-by-step actions you would take to diagnose and fix the issue, mentioning any settings or indicators you would check.
Ans>
## 🎧 Bluetooth Headphones Not Connecting to Phone

### Step-by-Step Troubleshooting Guide

**Step 1: Check the Headphones**
- Ensure the headphones are switched on.
- Check the battery level and charge them if necessary.
- Look for a blinking LED indicator showing pairing mode.

**Step 2: Check Bluetooth on the Phone**
- Open **Settings → Bluetooth**.
- Turn Bluetooth on.
- Verify that Bluetooth is enabled and the phone is discoverable if required.

**Step 3: Put Headphones into Pairing Mode**
- Follow the manufacturer's instructions to activate pairing mode.
- Check whether the LED flashes blue or alternates between blue and red, depending on the model.

**Step 4: Select the Headphones**
- Open the available Bluetooth devices list on the phone.
- Tap the headphone name.
- Accept the pairing request if prompted.
- Check that the status changes to **Connected**.

**Step 5: Check Existing Connections**
- Disconnect the headphones from other nearby phones, laptops, or tablets.
- Some headphones automatically reconnect to a previously paired device and may not accept a new connection.

**Step 6: Forget and Re-Pair**
- Open the phone's Bluetooth settings.
- Tap the settings icon beside the headphone name.
- Select **Forget** or **Unpair**.
- Put the headphones back into pairing mode and pair them again.

**Step 7: Restart Both Devices**
- Turn the headphones off and on again.
- Restart the phone.
- Enable Bluetooth and attempt pairing again.

**Step 8: Test the Audio**
- Play a song or video.
- Check the phone's audio output selector and select the Bluetooth headphones.
- Verify that the sound is coming through the headphones.

**Step 9: Test with Another Device**
- Try connecting the headphones to another phone or laptop.
- If they connect successfully, investigate the original phone's Bluetooth settings.
- If they fail on multiple devices, consult the headphone manufacturer's support guide.

### 🔍 Indicators to Check

| Indicator | What It Means |
|---|---|
| Blinking LED | Headphones may be in pairing mode. |
| Solid LED | May indicate a successful connection or another operating state, depending on the model. |
| Connected status | Phone reports that the headphones are paired and connected. |
| Low battery warning | Headphones may need charging. |
| Audio output selection | Confirms where the phone is sending sound. |

### ✅ Conclusion

Most Bluetooth connection problems can be resolved by checking battery power, enabling Bluetooth, activating pairing mode, forgetting and re-pairing the device, and restarting both devices.
# Q3.A user reports that their external webcam is not detected during a Zoom call on Windows 10. Write a checklist of 6 things to check or try to resolve the problem.<br><br><em><strong>Hint:</strong> Consider device manager, privacy settings, and app permissions.</em>
Ans>## 📷 Troubleshooting: External Webcam Not Detected in Zoom (Windows 10)

### ✅ Checklist

- [ ] **1. Check the USB Connection:** Ensure the webcam is properly connected to the USB port. Try another USB port if necessary.

- [ ] **2. Check Device Manager:** Open Device Manager and look under **Cameras** or **Imaging devices**. If the webcam is disabled, enable it. Update the driver if needed.

- [ ] **3. Check Camera Privacy Settings:** Go to **Settings → Privacy → Camera** and enable camera access for the device.

- [ ] **4. Check App Permissions:** Ensure that **Allow apps to access your camera** is enabled. If Zoom is listed, make sure it has permission to use the camera.

- [ ] **5. Check Zoom Settings:** Open Zoom → **Settings → Video** and select the correct external webcam from the Camera dropdown menu.

- [ ] **6. Close Other Apps and Restart:** Close other applications that may be using the webcam, restart Zoom, and reconnect the webcam. Restart the computer if the problem continues.

### 🔧 Conclusion
These troubleshooting steps can help identify and resolve common webcam detection issues in Windows 10 and Zoom.
# Q4.You are helping a friend whose printer is showing 'offline' status on their PC. Describe how you would use the Windows Troubleshooter tool to try to fix the issue, and explain what information the tool provides during the process.
Ans>## 🖨️ Troubleshooting a Printer Showing "Offline" in Windows

### Step-by-Step Procedure

1. **Open Settings:** Click the Start menu and open **Settings**.

2. **Go to Devices:** Select **Devices → Printers & scanners**.

3. **Select the Printer:** Choose the printer showing the "Offline" status.

4. **Run the Troubleshooter:** Click **Manage** and look for the available troubleshooting option. In Windows 10, you can also open **Settings → Update & Security → Troubleshoot → Additional troubleshooters → Printer → Run the troubleshooter**.

5. **Follow the Instructions:** Allow Windows to detect problems and follow the recommended actions. The tool may check printer connectivity, driver issues, and print spooler services.

6. **Apply Fixes and Test:** Apply any suggested fixes, then print a test page to check whether the printer is online and working.

### 🔍 Information Provided by the Troubleshooter

- **Detected Problems:** Identifies possible printer connection or configuration issues.
- **Diagnostic Results:** Reports problems found during the scan.
- **Recommended Solutions:** Suggests actions to resolve detected issues.
- **Fix Status:** Indicates whether Windows applied a repair successfully or whether further action is needed.

### ✅ Conclusion

The Windows Printer Troubleshooter helps identify and resolve common printer problems. If the printer remains offline, check its power, USB or Wi-Fi connection, default printer settings, and print queue.
